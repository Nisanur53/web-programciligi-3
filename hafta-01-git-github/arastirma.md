Git nedir? 

Yazılım geliştirme süreçlerinde kod değişikliklerini takip eden, birden fazla geliştiricinin aynı proje üzerinde çalışmasını koordine eden dağıtık bir sürüm kontrol sistemidir (Version Control System). Hangi kodun ne zaman, kim tarafından değiştirildiğini kaydeder. 

GitHub nedir? 

Git projelerinin bulut ortamında (uzak sunucularda) saklanmasını, yönetilmesini ve diğer geliştiricilerle paylaşılmasını sağlayan web tabanlı bir barındırma platformudur. 

Git ile GitHub arasındaki fark nedir? 

 Git: Bilgisayarınızda çalışan yerel bir araçtır (versiyon kontrolü yapar) 

GitHub: Git depolarının internet üzerinde depolandığı, ekip çalışmasına ve sosyal kodlamaya olanak tanıyan bir platformdur. 

Repository (Repo) nedir? 

 Bir projenin dosyalarının, klasörlerinin ve bu dosyalara ait tüm geçmiş sürüm/değişiklik geçmişinin saklandığı depodur (proje klasörü). 

Commit nedir? 

Projede yapılan değişikliklerin (ekleme, silme, düzenleme) Git veritabanına anlamlı bir açıklamayla kalıcı olarak kaydedildiği adım/mühürdür. 

Branch (Dal) nedir? 

 Ana projeyi (main/master) bozmadan yeni özellikler geliştirmek veya hataları düzeltmek için açılan bağımsız çalışma kollarındadır. 

Merge nedir? 

 Farklı branch'lerde (örneğin bir özellik dalında) yapılan çalışmaları ana banda (main branch) birleştirme işlemidir. 

Clone nedir? 

 Uzak bir sunucudaki (GitHub'daki) bir repository'yi tüm geçmişiyle birlikte yerel bilgisayara kopyalama işlemidir. 

 

Pull nedir? 

 Uzak sunucudaki (GitHub) en güncel değişiklikleri yerel bilgisayarınızdaki projeye çekmek ve senkronize etmek için kullanılır. 

Push nedir? 

Yerel bilgisayarınızda yaptığınız ve commit'lediğiniz değişiklikleri uzak sunucuya (GitHub'a) göndermek için kullanılır. 

.gitignore dosyasının amacı nedir? 

 Git tarafından takip edilmesini istemediğimiz dosya ve klasörleri belirtmek için kullanılır.
